### Definitions

- **Leak:** a returned memory whose true transitive source labels (from the generator, not from what was recorded in mem0) are not all held by the requester. **Leak rate** = leaked / returned.
- **Recall@10 (entitled):** for each query, run mem0 `search` with `top_k=500` and keep, in mem0's order, only memories the requester is truly entitled to; the ideal set is the first min(10, n) of these. A returned memory counts as a hit if it is in that entitled list with a score (in the same `top_k=500` call) at least that of the 10th ideal item, so ties at rank 10 are not penalised. Recall@10 = min(hits, |ideal|) / |ideal|, averaged over the 240 queries with at least one entitled memory (0 queries had none and are excluded).

### Reading the table

- **Content-only filtering removes raw restricted records but none of what was derived from them:** all 563 of its leaks are derived memories.
- **Plain mem0's lower recall is displacement.** It always returns 10 results, and restricted memories take slots that entitled ones would otherwise fill. In 170 of the 171 queries where plain mem0 misses entitled memories, every miss is matched by a restricted memory in its top 10. The remainder reflects mem0's ranking depending on `top_k`.
- **Different denominators.** Plain mem0 and the content-only filter return 2400 results (10 per query); the gate returns 2164. The gate came up short of 10 in 34 queries (236 empty slots). In 34 of those it returned every memory the requester is entitled to among all results mem0 returns for the query at any depth, i.e. fewer than 10 entitled memories pass mem0's score threshold. Leak rates are per returned item, so they use these different denominators.
- **Latency is tail overhead from over-fetch, at small scale.** Wall-clock per in-process `search` call on 420 memories with local Qdrant. When most top candidates are restricted, the gate issues several underlying searches, which shows up in p95 rather than p50. Latency was not measured at production scale, with a remote vector store, or with real embeddings.
